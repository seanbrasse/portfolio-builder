Comic portfolio motion reference

Runnable timings for the panel entrance sequence. Every value here maps to a CSS custom property at the top of the stylesheet, so the whole feel is tunable from six numbers.

1. The ink-in sequence

Each panel reenacts how a comic page is made: border inks, flats go down, the halftone screen lands, lettering comes last. The stagger between panels is the gutter, and it runs in reading order, which is how the animation teaches the eye where to travel.

4. Rules this encodes

Animate the reading, never the drawing. Nothing loops or drifts; motion happens on entrance and on interaction, then stops completely. Panels fire once via IntersectionObserver and never replay on scroll-back. Only transform, opacity, and stroke-dashoffset are animated. Default state in CSS is the finished state, so if JavaScript never runs the page is still fully readable.
